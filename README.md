## 📌 A few Featured Projects

### 🥈 Predicting Financial Deterioration Among Kenyan Adults: iLab Africa Data Sprint 2026 (Runner-up)
Multiclass model on the **2024 FinAccess Household Survey (20,871 respondents, all 47 counties)** predicting whether an adult's finances improved, stayed the same or worsened.
- **Approach:** data cleaning, class balancing with SMOTE, XGBoost classification
- **Finding:** emergency fund access, mobile money use, food insecurity and debt stress were key predictors
- **Outcome:** recommendations for policymakers and financial institutions; led the team to 2nd place
- **Repo:** [link]([https://github.com/WariaraM/REPO-NAME](https://github.com/WariaraM/DataSprint-2026-Predicting-Financial-Deterioration-Among-Kenyan-Adults))

### 🛒 Amazon Product Recommendation System
Personalised recommendation engine on Amazon's electronics ratings data.
- **Approach:** compared rank-based, user-user, item-item and matrix factorisation (SVD) models
- **Evaluation:** Precision@k, Recall@k and F1-score; user-user collaborative filtering performed best
- **Repo:** [link]([https://github.com/WariaraM/REPO-NAME](https://github.com/WariaraM/Amazon-Product-Recommendation-System))
